# 人狼メーカー V3.0.5

## 今回のテーマ
オリジナル役職を「完全自由なプログラム」ではなく、用意したパーツを組み合わせて作る方式に変更。

### 役職フォーマット
- 基本情報：役職名 / 陣営 / 説明
- 能力：発動タイミング / 効果 / 対象 / 使用制限
- 第三陣営：勝利条件
- 1役職につき最大3能力

### 発動タイミング
- ゲーム開始時
- 夜
- 投票時
- 処刑時
- 死亡時

### 初期能力
- 襲撃
- 陣営を調査
- 役職を調査
- 護衛
- 蘇生
- 道連れ
- 能力封印
- 自己脱落
- 投票数を+1

### 対象
- 自分
- 生存者1人
- 生存者（自分を含む）
- 死亡者1人
- ランダムな生存者
- ランダムなプレイヤー
- 全員
- 特定役職のプレイヤー

### 使用制限
- 無制限
- 1回
- 2回
- 3回

### 第三陣営の勝利条件
- 所属陣営の勝利
- 自分が生存してゲーム終了
- 自分が死亡してゲーム終了
- 自分が投票で処刑される
- 人狼陣営が全滅した時に自分が生存
- 村人陣営が全滅した時に自分が生存
- 最後まで生存

## 方針
最初から全ての特殊能力を実装せず、実際に役職を作って「足りない能力」を発見したら追加する。


## V3.0.1 修正
- 夜の能力選択が無限ループする不具合を修正。各夜につき各能力を1回選択できます。
- 配役設定を「村人陣営 / 人狼陣営 / 第三陣営」でグループ化。
- 占い結果を占い直後に画面通知。


## V3.0.5 修正
- 夜は生存者全員が「夜の行動を終了」ボタンを押す方式に変更。能力なしでも夜に参加しているように見える。
- 初日の夜に人狼同士がお互いを確認できる。
- ゲーム開始時の能力を個別通知で処理。全員の役職/陣営を知る能力にも対応。
- 「処刑されたら勝利」を処刑直後に判定。
- 生存型第三陣営の勝利条件を通常勝利成立時に判定。
- 個人情報通知は不透明なオーバーレイで表示。


## V4.1.0 更新内容
- 投票数+1をパッシブ能力として自動適用
- 遊び方・オリジナル役職作成ヘルプを追加
- 陣営人数だけ指定して役職をランダム割り当てするアサイン（闇鍋）を追加
- アサインは陣営内からランダム抽選・役職重複あり
